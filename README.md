# Red Social Estudiantil Pascualina

## Integrantes del equipo

## Descripción breve del caso
La red social estudiantil Pascualina busca mejorar la comunicación y la interacción entre estudiantes, permitiendo crear perfiles, conectar con compañeros, publicar actualizaciones, formar grupos y organizar eventos académicos o sociales.  
Este repositorio contiene el desarrollo de la **Tarea 1**, que incluye el informe en PDF, el diagrama MER y el video de sustentación.

## Estructura del repositorio
- Tarea1/Informe → Informe en PDF con el paso a paso del modelo conceptual.  
- Tarea1/Diagrama → Imagen del diagrama MER.  
- Tarea1/Video → Video de sustentación (5–10 minutos) con explicación del diagrama MER.
